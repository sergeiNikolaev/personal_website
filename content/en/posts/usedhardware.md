In this post, I decided to write about open devices and gadgets I am using or tracking. Not all of this is completely open hardware, since there are still proprietary parts somewhere. But it is much more configurable and customizable than other devices in general. The list might be helpful to find utilities for experiments or complex system construction.

1. [Fairphone](https://www.fairphone.com) - an open modular smartphone with an Android system. It is possible to replace the parts of the smartphone or add the ones that are self-manufactured according to the particular protocols.

2. [Arduino](https://www.arduino.cc) (hardware - CC BY-SA License, software - General Public License v3.0, Lesser General Public License v2.1) - an open source hardware and software electronic prototyping platform enabling users to create interactive electronic objects.

3. [Pine devices](https://pine64.org) - a list of devices, including smartphone PinePhone and notebook PineBook, that use open source firmware or certain Linux platforms. The systems allow access to most of the hardware features. However, there is only unofficial Android support for PinePhone, and PineBook GPU does not have Nvidia and AMD graphics power and possibilities.

4. [Flipper Zero](https://flipperzero.one) - a gadget with open source firmware to ~~hack~~ get access to radio spectrum waves, wireless control access systems, infrared ports and some other functionality.

5. [Steam Deck](https://www.steamdeck.com) - a game console with Steam OS (Linux-based), keyboard and mouse emulators, and a Proton library to play Windows-based video games. The software is not completely open because of system drivers and certain proprietary parts. Can be transformed to a desktop PC using a Deck station or a USB-C hub, together with a monitor, a keyboard, and a mouse.
