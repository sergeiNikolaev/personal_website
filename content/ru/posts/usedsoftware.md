Этот пост посвящён списку программного обеспечения, которое я использую (или принимаю во внимание на случай, когда мне потребуется дополнительная функциональность). Сейчас существует настолько много разнообразного программного обеспечения, что достаточно трудно выбрать что-то для персонального использования. И я решил создать этот список, чтобы сохранить информацию о программах, которые могут оказаться полезными в различных ситуациях. По умолчанию все перечисленные программы и утилиты имеют открытый исходный код и свободно доступны для Windows, Linux, macOS. Однако некоторые распространяются с определёнными ограничениями, которые указаны в описании. Те, что работают с ресурсами интернета: ([Brave](https://brave.com), [OnlyOffice](https://www.onlyoffice.com)), также доступны для Android и iOS. Кроме того, [LibreOffice](https://www.libreoffice.org/) и [Firefox](https://www.mozilla.org/en-US/firefox/), распространяющиеся под лицензией Mozilla Public License 2.0, хорошо известны, поэтому нет необходимости в их дополнительном описании.


* Интернет

1. [Brave](https://brave.com) (Mozilla Public License 2.0) — альтернативный браузер, блокирующий больше контента и более безопасный для работы в Интернете по сравнению с Firefox. Однако у него нет такого разнообразного набора дополнений. В итоге, я его использую параллельно с Firefox.


* Офис

2. [OnlyOffice](https://www.onlyoffice.com) (Affero General Public License v3.0) — ещё один свободный офисный пакет. Он является скорее альтернативой для Google Docs, чем для офиса Microsoft, так как позволяет совместное редактирование документов, используя ресурсы, предоставляющие разделяемый доступ к файлам.


* Обработка изображений

3. [GIMP](https://gimp.org) (General Public License v3.0) — редактор обработки изображений для растровой графики. Позволяет использовать различные инструменты для выбора, редактирования и фильтрации элементов изображения. Также имеется возможность добавления дополнительных плагинов и расширений.

4. [Inkscape](https://inkscape.org) (General Public License v2.0) — редактор обработки изображений для векторной графики. Есть различные инструменты для обработки векторных элементов на изображениях.

5. [Fiji](https://imagej.net/software/fiji) (General Public License v3.0) — редактор обработки трёхмерных изображений для растровой графики. Отличительной особенностью программы является расширенная поддержка плагинов, которые могут быть легко добавлены. Расширение можно создать на одном из нескольких языков, а сам редактор предоставляет большой интерфейс вызовов функций для доступа к изображениям.


* Создание изображений

6. [Krita](https://krita.org) (General Public License v3.0) — инструмент для рисования изображений. Имеет огромное число возможностей, помогающих создавать сложные изображения и анимацию.


* Обработка аудио

7. [Audacity](https://audacityteam.org) (General Public License v3.0) — достаточно легковесная библиотека, позволяющая фильтровать, очищать и модифицировать аудиозаписи, а также добавлять разнообразные эффекты к голосу.

8. [Ardour](https://ardour.org), [LMMS](https://lmms.io) (General Public License v2.0-v3.0) — более продвинутое программное обеспечение. В дополнение к разнообразным расширениям, оно позволяет выполнять запись с микрофона и эмулировать несколько цифровых музыкальных инструментов.


* Обработка видео

9. [Kdenlive](https://kdenlive.org) (General Public License v3.0) — легковесный инструмент для обработки и монтажа видео, а также наложения на него аудиозаписей. В наличии нет огромного количества функциональности, но имеющейся достаточно для создания хороших видео.

10. [Open Broadcaster Software](https://obsproject.com/) (General Public License v2.0) — свободное программное обеспечение для записи видео- и онлайн-трансляций.


* Обработка трёхмерных моделей (CAD)

11. [Blender](https://www.blender.org/) (General Public License v3.0) — мощный инструмент для работы с трёхмерной компьютерной графикой. Он позволяет создавать анимацию и визуальные эффекты. Важный момент заключается в том, что в Blender есть возможность выбирать и обрабатывать только часть модели.

12. [ParaView](https://www.paraview.org/) (BSD 3-clause license) — движок для постобработки и визуализации трёхмерных моделей. Он может обрабатывать полигональные (а не только треугольные) и неструктурированные сетки. Однако все изменения выполняются с помощью фильтров, поэтому возможности ручного редактирования ограничены. В ParaView также легко создавать анимацию из набора полигональных моделей.

13. [MeshLab](https://www.meshlab.net/) (General Public License v3.0) — более простой инструмент для обработки трёхмерных сеток. Тем не менее он содержит некоторые функции обработки, недоступные ни в ParaView, ни в Blender. Изменения также обычно выполняются с использованием различных фильтров.


* Создание трёхмерных моделей

14. [Gmsh](https://gmsh.info/) (General Public License v2.0-v3.0) — простой генератор двумерных и трёхмерных (поверхностных и объёмных) сеток. Форма генерируемого объекта описывается поверхностями с помощью входного файла определённого формата. Формат нетривиален, но существует возможность задавать его программно, например, на языке Python с помощью библиотеки pygmsh.


* Трёхмерное моделирование (CAE)

15. [SOFA](https://www.sofa-framework.org/) (Lesser General Public License v2.1) — это открытая платформа для моделирования мультифизических процессов в реальном времени, ориентированная в первую очередь на робототехнику и медицинские приложения. Она включает в себя визуализатор для наблюдения за процессом моделирования и различные плагины для расширения функциональности.

16. [FEBio](https://febio.org/) (FEBio License) — это программный инструмент для нелинейного конечно-элементного анализа в биомеханике и биофизике, специально предназначенный для решения нелинейных задач с большими деформациями в указанных областях.


* Расширенная реальность / создание игр

17. [Godot](https://godotengine.org) (Expat/MIT License) — свободный движок для создания игр и систем виртуальной реальности в дву- и трёхмерном пространстве. Поддерживает несколько языков программирования для создания игровых скриптов.


* Другие приложения

18. [Stellarium](https://stellarium.org) (General Public License v2.0) — открытый планетарий. Позволяет искать и наблюдать астрономические объекты на небе, а также симулировать перемещение в прошлое или будущее, чтобы наблюдать, где эти объекты были или будут.


* Системные приложения (почти все работают только на Linux), Windows и macOS имеют собственные инструменты для анализа и администрирования системы.

19. [Stacer](https://oguzhaninan.github.io/Stacer-Web) (General Public License v3.0) — инструмент для оптимизации Linux и системного мониторинга, интерфейс и функциональность которого аналогичны диспетчеру задач Windows. Предоставляет возможности управления приложениями, системными процессами и установки программного обеспечения (только для менеджеров пакетов, основанных на .deb).

20. [timeshift](https://github.com/linuxmint/timeshift) (General Public License v3.0) — инструмент для восстановления системы. Поддерживает создание точек восстановления и их использование для рабочей и нерабочей системы. В последнем случае восстановление производится из версии системы, установленной на CD-диск или USB-накопитель.

21. [htop](https://htop.dev) (General Public License v2.0), [btop](https://github.com/aristocratos/btop) (Apache License v2.0) — интерактивные мониторы ресурсов системы в командной строке. У Btop более приятный интерфейс и немного больше возможностей, но он не включён по умолчанию в дистрибутивы Linux.

22. [vokoscreenNG](https://linuxecke.volkoh.de/vokoscreen/vokoscreen.html) (General Public License v2.0) — (также доступен для Windows) — простой инструмент для создания фото- и видеоснимков экрана.
